# Double Trouble Darts public-release checklist

- [ ] The repository owner, credits and code provenance have been reviewed.
- [ ] README screenshots have been added if available (do not use third-party artwork without permission).
- [ ] Third-party assets or libraries are documented and permitted for redistribution.
- [ ] No internal user paths, passwords, secrets or private project files are included.
- [ ] Version in code and release tag is v4.1.0.
- [ ] Installation and uninstall/update steps were verified on the intended platform.
- [ ] Draft GitHub Release created with the named asset in `../releases`.
- [ ] All public links tested after the release is published.
